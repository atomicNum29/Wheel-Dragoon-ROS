# 개발 문서 안내

이 디렉터리는 과거 개발 기록과 보관 코드를 포함한다. 현행 사용법·타입·동작은 다음 문서를 따른다.

| 문서 | 내용 |
| --- | --- |
| [워크스페이스](../README.md) | 구성, 빌드, 센서·웹·MCU 실행 |
| [MCU 브리지](../src/my_car_mcu_bridge/README.md) | 송수신 규격, 토픽, 연결·집계 정책, 오류 의미 |
| [인터페이스](../src/my_car_interfaces/README.md) | 전용 메시지 필드·단위·flags |
| [웹 모니터](../src/my_car_web_monitor/README.md) | 웹 설정, 상태 표시, 영상·LiDAR, 구현 제약 |

`archive/documentation_before_split_rewrite/`는 구형 계획·보고서 원문이다. 문서 내부의 “현재”, 테스트 결과, 구형 경로는 당시 기록이며 현행 규격이나 검증을 뜻하지 않는다. 기존 계획·보고서 경로는 현행 문서로 안내한다.

`archive/pre_split_telemetry/`는 구형 변환·상태 선택 코드와 테스트다. 현행 패키지의 실행 코드·테스트 스위트가 아니다. 현재 웹 `test/`에도 구형 상태·제어 전제를 사용하는 항목이 남아 있다.

과거 기록 분리 이후 웹 제어와 0x03 명령 송신 코드가 추가되었다. 현행 동작은 위 문서를 따르며, 이번 제어 구현에서 빌드·테스트·장비 통신은 수행하지 않았다.
